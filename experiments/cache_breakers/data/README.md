Jane Austen (1813), public domain, taken from the Project Gutenberg eBook
#1342 with the Gutenberg header, footer and illustration markers removed.

filler (see `log.md`, 2026-09-18). `src/fixture.ts` draws seeded slices from
it, so every trial is still reproducible from its seed.
